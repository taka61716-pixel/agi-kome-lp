# あぎひかり LP

運営ブランド名は `阿木ファーム`、商品名は `あぎひかり` です

お米販売・予約受付用の静的ランディングページです

## 無料公開の方針

GitHub Pagesで公開する前提です
HTML / CSS / JavaScriptだけで作っているため、サーバー契約や有料CMSは不要です

## ファイル構成

- `index.html`: LP本体
- `styles.css`: デザイン
- `script.js`: 商品選択と注文メモ作成
- `assets/akigawa-field-hero-premium.jpg` / `.webp`: メインビジュアル（阿木川流域の実際の田んぼの写真）
- `assets/rice-hero.png`: 旧バージョン（差し替え前のストック画像、未使用・削除可）
- `.nojekyll`: GitHub Pagesで静的ファイルをそのまま配信するための設定
- `sales/予約管理表.csv`: 予約管理用テンプレート
- `sales/LINE先行案内文.md`: 先行案内と紹介依頼の文面
- `sales/Instagram投稿案.md`: Instagram投稿3本
- `sales/販売戦略メモ.md`: 1500kg販売の行動計画

## 公開手順

1. GitHubで公開リポジトリを作成する
2. このフォルダの内容をそのリポジトリへpushする
3. GitHubのリポジトリ画面で `Settings` → `Pages` を開く
4. `Build and deployment` の `Source` を `Deploy from a branch` にする
5. `Branch` を `main`、フォルダを `/root` にして保存する
6. 数分後に表示されるURLへアクセスする

無料URLの例:

```text
https://githubユーザー名.github.io/リポジトリ名/
```

## 公開前に差し替える項目

- 商品名
- 産地
- 品種
- 価格（税込表示）
- 送料
- LINE公式アカウントのURL（設定する場合のみ、公式アカウントURLを確認して追加）
- 販売者の正式名称、所在地、電話番号
- 特定商取引法に基づく表記の最終確認
- 商品ラベルに記載する調製時期、内容量、販売者情報
- 実物写真：ヒーロー画像は実際の田んぼの風景写真に差し替え済みただし人物（作り手）や実際の米袋の写真はまだ無いので、余裕があれば追加すると信頼性がさらに上がる
- og:image / twitter:image を絶対URL（https://から始まるURL）に変更（公開URL確定後）
- GA4計測ID（`index.html` 内の `G-XXXXXXXXXX` を2箇所、実際の測定IDに差し替え未設定のままだとアクセス解析は動きません）

## 予約フォームについて

`#order` セクションのフォームは Formspree（https://formspree.io/f/mbdwgyek）に接続済みです
これは以前このプロジェクトで使っていたフォームIDを復活させたものです公開前に必ず以下を確認してください

1. Formspreeの管理画面にログインし、このフォームIDが今のアカウントで有効か確認する
2. 実際に1件テスト送信し、登録しているメールアドレスに届くか確認する
3. 無料プランは月50件までの送信上限があるため、件数を超えそうな場合はプランを確認する

予約フォームをメインの受付経路にしています　LINE公式アカウントはURLと応答体制が確定してから追加してください
